# Emmvee Careers Platform

A full-stack careers and recruitment platform built with React, TypeScript, Spring Boot, Spring Security, JWT, JPA/Hibernate, and MySQL.

## Features

- User registration and login
- JWT authentication
- USER and ADMIN roles
- Protected routes
- Careers and job details
- Job applications
- My Applications dashboard
- Admin application dashboard
- Application status management
- Admin job management
- Backend authentication and job service tests

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL
